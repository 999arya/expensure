How Expensure's AI Coach works

Financial rules and allowance equations are calculated in Python first. The AI receives only compact numerical summaries without personal identifiers or full account numbers.

  • Does not connect directly to banks or read raw message text.
  • Never moves money, changes account balances, or silently alters goals.
  • Calculations work on the server without an AI key. AI can select verified explanations; the Python result always controls the verdict.
