Android: optional forwarding

  1. Use an automation app you trust that supports an incoming SMS trigger, custom HTTP headers, and a JSON POST body. Menu names depend on the app; this is a connection recipe, not an installed integration.
  2. Grant the SMS permission it needs. Restrict the trigger to your bank's sender and transaction phrases; exclude OTP and verification messages.
  3. Configure its HTTP request with the settings above and map the received SMS body to message.
  4. Test one supported transaction alert. Check Recent Capture Events below and review the resulting transaction in your ledger.
  5. If forwarding stops, check internet access, SMS permissions, and the phone's background/battery restrictions for that app. Manual paste remains available without an extra app.

iPhone: Apple Shortcuts

  1. Open Shortcuts → Automation → + → Message.
  2. Choose the bank sender and one Message Contains phrase such as debited. Create another automation for credited or other phrases your bank uses. A comma-separated list is not an OR filter.
  3. Choose Run Immediately if your iOS version offers it; otherwise approve the notification when it runs.
  4. Create a blank automation and add Get Contents of URL. Enter the URL above, select POST, and add the two headers.
  5. Set Request Body to JSON. Add a Text field named message and select the incoming message's text from Shortcut Input (Content if offered). Do not type "Shortcut Input" as literal text.
  6. Save, test with one transaction alert, and check Recent Capture Events. Review its time, account and category in your ledger. Existing messages must be pasted manually.

Setup reference: Apple message triggers, Apple web requests, and Android SMS permissions.

If the balance does not change

Capture is only the first step. Open the ledger and resolve pending reviews. Unsupported messages or unmatched accounts are not imported; check the bank name and last four digits. Never change an old transaction's time just to force it into the current balance.

If the free server is asleep, the first request may take about a minute. Check capture events before resending. For missed or unsupported messages, enter the transaction manually or confirm the current balance from your bank app.
